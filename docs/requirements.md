# ShareBox 项目需求

## 1. 项目定位

ShareBox 是个人服务器上的统一文件中转、管理与分发平台，以统一 Web 入口满足三个场景：

| 场景 | 文件流向 | 负责模块 |
| --- | --- | --- |
| 对外发布文件夹 | 服务器 → 外部用户 | Sharing：目录发布、匿名浏览与下载、取消发布 |
| 自己跨设备传递文件 | 设备 A → 服务器 → 设备 B | Transfer：认证后的上传、私有浏览与下载 |
| 服务器代下载 | 外部资源 → 服务器 | Acquisition：HTTP/HTTPS 获取、持久化任务与失败恢复 |

文件内容在文件系统中保留一份，由统一文件管理能力维护。文件默认私有，公开访问来自显式分享规则，不以两套 public/private 文件副本表达权限。产品保持单服务器、个人使用和低部署成本，不扩展为完整协作网盘或通用下载管理器。

第 2 节记录现有实现；第 3 节起是已确定方向、尚待开发和验收的目标需求，不能视为当前可用能力。

项目技术栈为 Node.js、TypeScript、React Router Framework 和 MUI。技术实现见 [架构设计](architecture.md)。

## 2. 当前版本

### 2.1 角色与访问边界

- 单服务器、单管理员，不提供注册或多用户系统。首次启动自动生成用户名 admin、32 位随机密码及会话密钥，提交到 SQLite 后控制台输出一次初始密码。数据库只保存密码哈希，不强制改密，重启不重新生成或输出密码；不兼容旧认证环境变量。
- 管理页 `/` 未登录跳转 `/login`；私有下载 `/download?path=...`、文件操作及 tus 上传均要求管理员会话，匿名请求返回 401。
- 文件统一保存在 `STATE_DIR/files/`，默认私有。旧 `/public` 及其下载入口已移除，返回 404。
- 匿名访客只能通过有效 `/s/:shareId` 获取被显式分享的单个文件，不能浏览文件空间或目录。
- 生产环境通过单个 HTTPS 域名访问，应用自身不监听 TLS。签名 Cookie 使用 HttpOnly、SameSite=Lax，生产启用 Secure 和 `__Host-`；会话固定有效 7 天。写请求验证同源 Origin。

### 2.2 文件管理与私有下载

- 管理页支持目录导航、面包屑、当前目录名称筛选、名称/大小/修改时间排序和手动刷新。
- 文件列表来自文件系统，忽略符号链接和特殊文件；服务器上直接变更内容后可刷新查看。
- 文件行及操作菜单中的下载操作提供认证后的流式附件下载，支持 HEAD、单段 Range、416 和原文件名。
- 支持重命名文件或目录、删除文件或空目录，操作前确认。非法路径、符号链接、同名重命名与非空目录删除被拒绝。
- 支持在当前目录创建私有空目录、上传文件；同名目标拒绝覆盖。支持移动、复制文件与目录（含子项），操作菜单通过目录选择对话框确认目标；拒绝原目录、源目录及其子目录。副本默认私有且不继承分享；暂不支持整个目录上传。

### 2.3 上传与恢复

- 文件选择与拖放支持多文件 tus 分块上传，最多保留 100 个任务，同时传输 2 个文件，默认每文件上限 10 GiB。
- 显示字节进度和状态，支持暂停、继续、失败重试、取消；刷新后保留任务记录及目标目录，在任务的目标目录重新选择原文件即可恢复。每个任务在入队时固定目标目录，浏览目录变化不改变已有任务。续传以服务器偏移为准。
- 暂存及完成回执位于 `STATE_DIR/staging/`，任务及回执保留 7 天；取消上传不删除已完成文件。
- 最终响应成功前完成落盘；复制失败和最后响应丢失后可由 tus HEAD/完成钩子恢复，不另建任务重复传输。
- 上传落盘仍采用不覆盖复制，尚未原子提交：复制期间及进程崩溃后可能出现不完整文件。同名文件拒绝覆盖。

### 2.4 单文件分享

- 文件行提供“分享/管理分享”，上传面板下方显示分享列表；目录不提供分享入口，根目录文件允许分享。
- 创建前明确告知拥有链接者可以匿名下载；确认后展示链接，支持复制、打开、手动选择复制和取消发布。界面适配桌面及窄屏基本操作。
- 列表显示文件相对路径、有效/失效状态及操作；刷新文件列表时重新核对文件身份，失效项可重新分享或取消发布。
- 创建、撤销接口为管理员同源 POST，接受不超过 16 KiB 的 URL 编码表单。一个路径只有一条记录，重复创建同一文件返回原链接。
- 分享 id 为 16 字节随机 hex；分享记录保存相对路径及 bigint dev/ino 字符串。文件内容保留一份，不复制公开副本。
- `/s/:shareId` 直接返回附件，支持 GET/HEAD、单段 Range 和 416，不增加落地页或路径参数。每次请求核对普通文件及打开句柄的身份。
- 撤销、未知 id、文件缺失或身份不符返回 404；响应禁止缓存与索引，日志脱敏分享 token。撤销不收回副本，也不终止已开始的传输。
- 管理员重命名文件或父目录后更新对应分享路径，链接继续有效；删除文件或空目录后清理精确路径及子路径记录。相邻名称前缀的分享不受影响。
- 文件操作成功但数据库同步失败时记日志并显示提醒，保持文件操作成功结果；旧路径记录不能通过替换文件继承公开权限。
- 服务器上直接移动或替换目标使链接失效，不自动重新绑定；原地修改且 inode 不变时提供最新内容。重新分享替换旧记录并生成新链接。
- 不实现目录发布、密码、有效期、下载次数或统计。

### 2.5 持久化、迁移与运行

- 使用 SQLite + Drizzle ORM + better-sqlite3 保存单例管理员凭据与分享规则，文件内容仍在文件系统。数据库为 `STATE_DIR/state.db`，权限 0600，启用 WAL 和 5000 ms busy timeout。
- 存储初始化后、处理请求前应用 `drizzle/` 迁移；空库初始化、版本升级、失败事务回滚、未来版本及不匹配迁移历史拒绝启动均有测试。
- 迁移前备份整个运行状态至 `STATE_DIR/backups/pre-migration-*`，排除历史备份；备份失败不执行迁移。升级及回滚须停机，只支持单实例。
- 旧 `data/`、`tmp/tus*` 必须先运行迁移脚本；保留文件且默认不创建分享。旧布局及新旧共存的歧义布局拒绝启动。
- 配置、数据库、日志与暂存不放在文件空间中，不对外提供。非 root 运行和端口绑定沿用部署默认值，HTTPS 由部署环境提供。
- 备份、恢复及 dev/ino 变化的限制见 [README](../README.md#单文件分享)。

忘记密码时停机执行 `npm run auth:reset`，输出新随机密码并轮换会话密钥，保留文件与分享。重新启动后旧会话失效。

### 2.6 当前验收

1. 未分享文件不能匿名读取；正确登录后可浏览、上传、私有下载、重命名和删除。
2. 根目录文件可分享，目录、符号链接及越界路径拒绝；重复创建幂等，撤销立即 404。
3. 分享 GET/HEAD/Range/416、未知 id、文件替换与重启持久化通过自动测试。
4. 文件及父目录重命名或移动后原链接可用，删除清理记录；同步失败不会将已完成文件操作误报失败。
5. 页面可创建、复制、管理、重新分享与取消发布，状态在 action 后自动刷新；桌面与手机宽度下可操作。
6. 服务端测试、类型检查、构建、Biome lint/check 通过；容器 Alpine 镜像实际构建仍需有 Docker/Podman 的环境验收。

## 3. 目标需求（待实现）

### 3.1 统一文件空间与管理

- 所有文件统一存放，上传与代下载只负责不同的获取方式；完成落盘不等于公开分享。上传完成落盘不会自动创建分享。
- 新上传、代下载取得的文件和新建目录默认私有，只有通过认证的管理员可以浏览和下载。
- 已支持在当前目录创建私有空目录、上传文件至当前目录；已支持移动和复制文件与目录；后续支持选择代下载的目标目录；同名目标默认拒绝，避免静默覆盖。
- 保持文件系统为文件内容和目录列表的来源；SQLite 保存分享规则及远程下载任务状态，不保存文件内容。
- 移动、重命名或删除分享目标时，必须同步维护分享规则，防止路径被其他文件复用后意外继承公开权限；当前分享使用路径及 dev/ino；移动已沿用此边界，复制不继承分享记录。

### 3.2 Transfer：跨设备传递

- 管理员在设备 A 经认证上传到指定目录，在设备 B 经认证浏览、下载同一文件，无需先创建公开链接。
- 复用 tus 分块上传、暂停、继续和失败恢复能力；私有下载支持流式响应、HEAD 和 HTTP Range。
- 管理页面适配桌面与手机基本操作，支持选择文件、查看进度、浏览目录和下载。
- 可选临时传输区域属于后续扩展，仍使用统一文件空间；第一阶段不引入自动过期删除、设备同步或 P2P 直连。

### 3.3 Sharing：目录发布

- 管理员选择一个目录并显式发布，获得可复制的公开访问链接；允许多个目录分别发布，分享引用原目录及其当前子项，不复制文件。
- 访客无需管理员凭据，通过有效链接浏览目录、查看文件大小并下载文件；链接只允许访问所发布的目录树。
- 目录中的后续新增、修改和删除反映在分享中。向已分享目录上传或移动文件前，界面应明确提示其会公开。
- 分享列表显示目标目录、访问链接与状态；管理员可以取消发布，取消后新的浏览和下载请求立即失效。已下载的副本无法收回，已开始的传输不承诺强制终止。
- 未分享目录、父目录和兄弟目录不可通过猜测路径、编码路径、符号链接或旧链接访问；失效分享不暴露目标文件信息。
- 分享状态在重启后保留。密码、有效期、下载次数限制与统计不属于首期范围。

### 3.4 Acquisition：HTTP/HTTPS 代下载

- 管理员输入 HTTP/HTTPS URL 并选择私有目标目录，创建后台任务；关闭页面不影响执行。
- 持久化任务来源、目标、状态、已下载字节和错误信息；界面提供排队、下载中、暂停、完成、失败和取消状态，支持暂停、继续、失败重试与取消。
- 并发数和任务大小上限有合理默认值，并允许部署配置；远端未提供总大小时显示已下载字节，不显示虚假百分比。
- 下载流式写入不可访问的临时目录，验证实际长度及可用的资源校验信息后完整落盘到指定目录；未完成文件不能经私有下载或分享暴露，同名目标不能覆盖。
- 重启后恢复任务记录并核对临时文件。续传应校验远端资源标识与 Range 响应；资源变化或不支持续传时明确提示重新下载，不得拼接不同版本内容。
- 取消及失败清理只影响任务临时数据，不删除已完成文件；完成落盘与任务状态更新应可恢复，重试不得重复生成文件或误报成功。
- 只接受 HTTP/HTTPS，拒绝本机、内网、链路本地和其他非公网目标；初始 URL、每次重定向及实际连接地址均须校验，覆盖 IPv4、IPv6 和 DNS 解析变化。
- URL 中的认证信息和敏感查询参数不能写入普通日志；任务创建、状态变化、重试、取消、落盘与安全拒绝应记录可追踪日志。
- 完成后文件保持私有，管理员可再通过 Sharing 发布。首期不支持 BT/Magnet；未来如需支持，交由独立 qBittorrent 服务执行。

### 3.5 认证、存储与部署边界

- 管理页面、私有浏览下载、上传和任务操作全部要求认证；匿名请求仅能通过有效分享入口读取被发布内容。
- 首期保持个人单管理员使用，不要求注册、多租户或角色系统；沿用现有应用登录与会话认证，公开分享权限由 ShareBox 判定。
- 任何部署入口都不能绕过应用直接公开文件空间；私有入口与分享入口均需经过相应权限检查。
- 逻辑模块化、部署保持单体；仅当下载执行影响 Web 服务，或需要独立重启和资源隔离时再拆 Worker。
- 关键边界与状态变化记录日志；服务端逻辑变更必须运行或编写测试，函数按职责拆分。

## 4. 实施顺序与迁移

| 阶段 | 范围 | 完成条件 |
| --- | --- | --- |
| 1（已完成） | 私有文件与公开分享边界、旧数据迁移 | 移除公开存储直出路径，认证后可读写，匿名不可读取未分享文件 |
| 2（已完成） | 单文件分享 | 可创建、复制、重新分享与撤销；重命名/删除联动，规则持久化 |
| 3 | 完善文件管理和跨设备传递 | 可创建目录、移动、选择上传目标，手机与桌面可上传及私有下载 |
| 4 | 目录发布 | 可创建、复制和撤销分享链接，权限与状态持久化 |
| 5 | HTTP/HTTPS 代下载 | 任务持久化、限流、恢复、完整落盘及 SSRF 防护通过验收 |
| 6 | 按实际需求扩展 | BT/Magnet 通过外部下载器接入，另行设计与验收 |

迁移必须在切换前备份完整状态目录并停止旧实例，核对文件和权限。旧 `data/` 中的文件保留，但不得静默把整个目录转换成新分享：迁移后默认私有，由管理员明确选择需要重新发布的目录。旧公开链接可能失效，升级说明必须说明影响及重新发布步骤。

迁移必须同步移除任何旧公开目录的静态直出配置；仅改应用权限无法保护仍由部署入口直接提供的文件。数据库、配置、日志、上传和下载临时文件都不得匿名访问。旧布局迁移、私有目录布局与分享数据库迁移已实现；恢复流程见 README。

## 5. 目标版本验收标准（待执行）

1. 新上传和代下载文件默认私有，匿名请求无法列目录、直接下载或通过任何旧直出路径访问；管理员可以在另一台设备认证后下载完整内容。
2. 新建目录、移动和指定目标上传成功；同名冲突保持原文件不变，越界路径与符号链接访问被拒绝。
3. 发布目录后匿名可浏览和下载其子项，不能访问父目录、兄弟目录或临时文件；新加入的子项按目录分享规则可见。
4. 撤销分享后新的列表、HEAD、Range 和下载请求均不可访问，重启后保持撤销；目标移动、删除再重建不会意外公开新文件。
5. 上传或代下载中断、失败、服务重启及完成响应丢失后，未完成内容均不可读；恢复或重试后不覆盖、不重复生成文件、不误报成功。
6. 下载任务关闭页面后继续执行，状态和进度可恢复；暂停、继续、重试、取消及并发限制符合配置。远端忽略 Range 或资源变化时不会错误拼接。
7. HTTP/HTTPS 获取覆盖重定向至内网、IPv6、本机及 DNS 变化的拒绝测试，安全拒绝和任务状态有日志且不泄露敏感 URL。
8. 旧数据迁移保留内容，默认不产生分享；旧直出入口关闭，升级说明能指导管理员重新发布。当前第 2 节的验证不能替代后续目标验收。

## 6. 后续可选扩展

以下功能不属于首期目标，需实际需求驱动另行设计：

- 临时传输区域与可配置过期清理。
- BT/Magnet 外部下载器适配。
- 分享密码、有效期、下载次数限制和统计。
- 同名覆盖策略、批量操作、递归删除和回收站。
- 文件描述、标签、搜索、排序和预览。
- 多管理员与角色权限。
- WebDAV、自动同步、P2P、S3、多服务器、独立 API、CLI 和原生移动客户端。
