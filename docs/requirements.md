# ShareBox 项目需求

## 1. 项目定位

ShareBox 是部署在个人服务器上的简单文件分享工具。管理员通过管理页面添加和删除文件，访客通过同域名下的 `/public` 页面浏览和下载文件，Caddy 提供 HTTPS 和反向代理，应用提供管理员登录认证。

项目技术栈为 Node.js、TypeScript、React Router Framework 和 MUI。技术实现见 [架构设计](architecture.md)。

## 2. 当前版本

### 2.1 使用角色

| 角色 | 能力 |
| --- | --- |
| 管理员 | 通过认证后查看、添加和删除文件 |
| 访客 | 无需认证，浏览和下载公开文件 |

当前版本面向单服务器和单个管理员凭据，不提供注册或用户管理。

### 2.2 管理端认证

- 管理端使用应用登录页 `/login`，固定单个管理员，凭据通过环境变量配置。
- 密码使用带随机盐的 scrypt 哈希，配置中不保存明文密码。
- 签名 Cookie 会话固定有效 7 天，服务端检查签名、到期时间和凭据版本；支持 POST 退出。
- 管理页及其 loader、文件操作、全部 tus 上传方法在服务端验证会话；未登录页面跳转登录，操作和上传返回 401。
- 公开浏览及下载允许匿名访问；生产环境要求 HTTPS，Cookie 使用 HttpOnly、SameSite=Lax 和 Secure。
- 单进程共享登录限流为 15 分钟最多 10 次尝试，成功登录重置；不提供注册、会话设备管理或单独撤销会话。

### 2.3 文件管理

- 所有公开文件位于状态根目录的 `data/` 及其子目录中，以可展开、收起的目录树展示；部署只配置一个状态根目录，内部公开目录和私有上传目录由程序维护。
- 文件树显示文件名、文件大小及目录子项数量。
- 支持浏览已有子目录；当前不提供新建目录。
- 管理员可以向公开根目录添加文件。
- 管理员可以删除根目录或子目录中的文件和空目录，删除前需要确认；非空目录拒绝删除。
- 添加同名文件时拒绝操作，不覆盖已有文件。
- 文件系统是文件列表的唯一数据来源。通过服务器直接添加或删除文件后，刷新页面即可看到结果。

### 2.4 文件上传

- 使用文件选择框或拖放选择多个文件，通过 tus 协议分块传输。
- 浏览器最多保留 100 个上传任务，同时上传最多 2 个文件，默认每个文件最大 10 GiB。
- 显示每个文件的已发送字节数、百分比和状态；支持暂停、继续、失败重试和删除上传任务。
- 断线保留已落盘数据，续传以服务端偏移量为准；服务器重启后可恢复。刷新页面保留任务记录，需重新选择原文件才可继续发送。
- 上传成功后刷新文件列表并显示结果。
- 上传失败时显示错误，保留临时文件供续传或通过 tus 恢复自动重试完成处理；删除上传任务时清理临时数据，创建满 7 天后自动清理。发布采用复制后删除临时文件，不保证原子性：复制期间可能下载到不完整文件，进程被强制终止或清理失败时可能留下残缺文件。
- 单文件大小上限由部署配置决定，整批总大小可超过单文件上限。
- 文件名、大小校验与结果按任务独立处理。复制失败保留完整上传数据；传输完成后由 tus 完成钩子自动发布，不提供独立发布操作；只有发布完成后才显示成功。最后响应丢失或恢复请求失败不得误报成功，也不得丢弃仍然有效的上传地址并重新传输整个文件。

### 2.5 公开浏览与下载

- 应用在 `/public` 提供匿名公开文件页面，通过服务端 loader 按目录读取文件系统；支持面包屑、返回上级、当前目录名称筛选、名称/大小/修改时间排序和手动刷新。
- `/public/download?path=...` 提供流式附件下载，保留原文件名，支持 HEAD 和单段 Range；拒绝非法路径、符号链接和目录下载。
- 点击公开页文件整行触发下载，目录整行进入查看。
- 访客可以看到文件名、大小和修改时间，通过下载按钮保存文件；空目录、无匹配项、加载中和读取失败有对应反馈。
- 文件不存在时返回未找到。
- 公开页面及下载入口需要应用运行。
- 管理端提供公开页入口，以及文件下载链接的生成、展示和复制；链接为同域名的公开下载地址，不创建 Token 或单独保存链接记录。

### 2.6 页面需求

| 页面 | 内容与操作 | 状态 |
| --- | --- | --- |
| 登录页 `/login` | 用户名、密码、登录、公开页入口、主题切换 | 提交中、凭据错误、尝试过多 |
| 文件管理页 | 目录树、文件选择和拖放区域、上传按钮、删除确认、手动刷新 | 加载中、空列表、提交中、成功、失败 |
| 公开文件页 `/public` | 目录浏览、筛选、排序、刷新和单文件下载 | 加载中、正常列表、空目录、无匹配项、未找到、读取失败 |

管理页面只需桌面端基础布局；公开文件页提供桌面和窄屏布局。

### 2.7 运行约束

- 使用单个 HTTPS 域名，`/public` 及其下载和 loader 入口匿名开放；管理页面、管理 loader 和写操作要求认证。
- 管理应用只能操作配置的公开根目录，不能访问服务器其他路径。
- 上传只接受普通文件；目录仅支持浏览和空目录删除。管理端和公开端忽略符号链接及其他特殊文件，拒绝通过它们进行上传或删除。
- 上传内容不能一次性完整载入应用内存。
- 配置、密码哈希、日志和上传临时文件不能放在公开目录中。

### 2.8 验收标准

1. 匿名管理页跳转登录，匿名管理操作及上传返回 401；正确凭据可以登录，错误凭据、篡改或过期会话不能访问管理功能。
2. 管理页展示公开根目录及子目录中的文件和目录，不显示符号链接或其他特殊文件。
3. 管理员选择多个文件并提交后，显示各文件结果，成功的文件出现在列表中，公开端可以获取完整内容。
4. 接收阶段中断时不发布文件，继续后内容完整；暂停保留任务，删除上传清理临时数据且不删除公开文件。复制失败可重试，不保证复制期间或进程被强制终止后没有残缺文件。
5. 上传同名文件时操作失败，原文件保持不变。
6. 管理员确认删除后，文件或空目录从列表消失；取消确认时内容不变；非空目录删除失败。
7. 访客无需认证即可浏览和下载公开文件。
8. 管理页生成的链接与公开页使用同一域名，可匿名下载对应文件。

### 2.9 验证记录与部署约定

- 旧的双域名与 Caddy 直接文件服务部署曾由部署者手动验证（2026-09-13）。此记录来自部署者确认，不作为当前单域名代理配置的验收证据。
- 非 root 运行、宿主机端口仅发布到本机由 Docker 镜像及部署命令的用户、端口绑定与文件权限默认值提供，不作为产品验收约束。
- 示例配置见 [`Caddyfile.example`](../Caddyfile.example)。

## 3. 后续可能扩展

以下功能不属于当前版本，需要出现实际需求后再设计和实现：

- 新建目录、移动和非空目录递归删除。
- 文件重命名、同名覆盖策略、批量操作和回收站。
- 分享 Token、密码、有效期、下载次数限制和私有文件。
- 文件描述、标签、跨目录搜索、预览和下载统计。
- 多管理员、角色和权限管理。
- 远程 URL 下载、BT/Magnet、WebDAV 和同步客户端。
- S3 等对象存储、多服务器、独立 API、CLI 和移动客户端。
