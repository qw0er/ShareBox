# ShareBox 项目需求

## 1. 项目定位

ShareBox 是部署在个人服务器上的简单文件分享工具。管理员通过管理页面添加和删除文件，访客通过 Caddy 提供的公开页面浏览和下载文件。

项目技术栈为 Node.js、TypeScript、React Router Framework 和 MUI。技术实现见 [架构设计](architecture.md)。

## 2. 当前版本

### 2.1 使用角色

| 角色 | 能力 |
| --- | --- |
| 管理员 | 通过认证后查看、添加和删除文件 |
| 访客 | 无需认证，浏览和下载公开文件 |

当前版本面向单服务器和单个管理员凭据，不提供注册或用户管理。

### 2.2 管理端认证

- 管理端使用 Caddy Basic Auth。
- 浏览器显示原生用户名和密码提示。
- 未通过认证的请求不能访问管理页面或执行文件操作。
- 用户名和密码哈希由部署者在 Caddy 配置中维护。
- 应用不实现登录页、退出功能、账号和会话管理。

### 2.3 文件管理

- 所有文件位于配置的公开根目录及其子目录中，以可展开、收起的目录树展示。
- 文件树显示文件名、文件大小及目录子项数量。
- 支持浏览已有子目录；当前不提供新建目录。
- 管理员可以向公开根目录添加文件。
- 管理员可以删除根目录或子目录中的文件和空目录，删除前需要确认；非空目录拒绝删除。
- 添加同名文件时拒绝操作，不覆盖已有文件。
- 文件系统是文件列表的唯一数据来源。通过服务器直接添加或删除文件后，刷新页面即可看到结果。

### 2.4 文件上传

- 使用文件选择框或拖放选择多个文件，通过 tus 协议分块传输。
- 浏览器最多保留 100 个上传任务，同时上传最多 2 个文件，默认每个文件最大 10 GiB。
- 显示每个文件的已发送字节数、百分比和状态；支持暂停、继续、失败重试和删除上传任务。
- 断线保留已落盘数据，续传以服务端偏移量为准；服务器重启后可恢复。刷新页面保留任务记录，需重新选择原文件才可继续发送。
- 上传成功后刷新文件列表并显示结果。
- 上传失败时显示错误，保留临时文件供续传或重试发布；删除上传任务时清理临时数据，创建满 7 天后自动清理。发布采用复制后删除临时文件，不保证原子性：复制期间可能下载到不完整文件，进程被强制终止或清理失败时可能留下残缺文件。
- 单文件大小上限由部署配置决定，整批总大小可超过单文件上限。
- 文件名、大小校验与结果按任务独立处理。复制失败保留完整上传数据；传输完成不等同发布成功，只有发布完成后才显示成功。

### 2.5 公开浏览与下载

- Caddy 直接提供公开根目录的文件列表和文件下载。
- 访客可以看到文件名、大小和修改时间，并点击文件名下载或打开文件。
- 文件不存在时返回未找到。
- 管理应用停止时，已存在文件仍可由 Caddy 提供。
- 管理端不提供复制链接、生成分享链接或管理链接的功能。

### 2.6 页面需求

| 页面 | 内容与操作 | 状态 |
| --- | --- | --- |
| 文件管理页 | 目录树、文件选择和拖放区域、上传按钮、删除确认、手动刷新 | 加载中、空列表、提交中、成功、失败 |
| 公开文件页 | Caddy 文件列表和文件入口 | 正常列表、空列表、未找到 |

管理页面只需桌面端基础布局，不要求自定义公开页面样式。

### 2.7 运行约束

- 管理端和公开端均使用 HTTPS，并使用不同域名。
- 管理应用只能操作配置的公开根目录，不能访问服务器其他路径。
- 上传只接受普通文件；目录仅支持浏览和空目录删除。管理端忽略符号链接及其他特殊文件，拒绝通过它们进行上传或删除。
- 上传内容不能一次性完整载入应用内存。
- 配置、密码哈希、日志和上传临时文件不能放在公开目录中。

### 2.8 验收标准

1. 未提供或提供错误凭据访问管理端时，Caddy 返回 401。
2. 管理页展示公开根目录及子目录中的文件和目录，不显示符号链接或其他特殊文件。
3. 管理员选择多个文件并提交后，显示各文件结果，成功的文件出现在列表中，公开端可以获取完整内容。
4. 接收阶段中断时不发布文件，继续后内容完整；暂停保留任务，删除上传清理临时数据且不删除公开文件。复制失败可重试，不保证复制期间或进程被强制终止后没有残缺文件。
5. 上传同名文件时操作失败，原文件保持不变。
6. 管理员确认删除后，文件或空目录从列表消失；取消确认时内容不变；非空目录删除失败。
7. 访客无需认证即可浏览和下载公开文件。
8. 管理应用停止后，Caddy 仍能提供已有文件。

### 2.9 验证记录与部署约定

- Caddy 认证、HTTPS、公开浏览下载，以及管理应用停止后仍能下载已有文件，已由部署者手动验证（2026-09-13）。此记录来自部署者确认。
- 非 root 运行、仅监听本机和 Caddy 对公开目录只读由部署脚本的用户、监听地址与文件权限默认值提供，不作为产品验收约束。
- 示例配置见 [`Caddyfile.example`](../Caddyfile.example)。

## 3. 后续可能扩展

以下功能不属于当前版本，需要出现实际需求后再设计和实现：

- 新建目录、移动和非空目录递归删除。
- 文件重命名、同名覆盖策略、批量操作和回收站。
- 复制公开地址、分享 Token、密码、有效期、下载次数限制和私有文件。
- 文件描述、标签、搜索、排序、预览和下载统计。
- 应用内登录、退出、多管理员、角色和权限管理。
- 远程 URL 下载、BT/Magnet、WebDAV 和同步客户端。
- S3 等对象存储、多服务器、独立 API、CLI 和移动客户端。
