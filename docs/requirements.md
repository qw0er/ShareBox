# ShareBox 项目需求

## 1. 项目定位

ShareBox 是部署在个人服务器上的简单文件分享工具。管理员通过管理页面添加和删除文件，访客通过 Caddy 提供的公开页面浏览和下载文件。

项目技术栈为 Node.js、TypeScript、React Router Framework 和 MUI。技术实现见 [架构设计](architecture.md)。

## 2. 当前版本

### 2.1 使用角色

| 角色 | 能力 |
| --- | --- |
| 管理员 | 通过认证后查看、添加和删除文件 |
| 访客 | 无需认证，浏览和下载公开文件 |

当前版本面向单服务器和单个管理员凭据，不提供注册或用户管理。

### 2.2 管理端认证

- 管理端使用 Caddy Basic Auth。
- 浏览器显示原生用户名和密码提示。
- 未通过认证的请求不能访问管理页面或执行文件操作。
- 用户名和密码哈希由部署者在 Caddy 配置中维护。
- 应用不实现登录页、退出功能、账号和会话管理。

### 2.3 文件管理

- 所有文件位于同一个公开根目录，以单层列表展示。
- 列表显示文件名和文件大小。
- 不创建或展示子目录。
- 管理员可以添加文件。
- 管理员可以删除文件，删除前需要确认。
- 添加同名文件时拒绝操作，不覆盖已有文件。
- 文件系统是文件列表的唯一数据来源。通过服务器直接添加或删除文件后，刷新页面即可看到结果。

### 2.4 文件上传

- 使用基础 HTML 文件上传：`<form method="post" enctype="multipart/form-data">` 和 `<input type="file">`。
- 当前版本支持一次选择并上传一个文件。
- 提交后使用浏览器和 React Router 表单的基础提交状态，不实现拖放、上传进度条、分块上传或断点续传。
- 上传成功后刷新文件列表并显示结果。
- 上传失败时显示错误，失败或中断的上传不能在公开目录中留下残缺文件。
- 文件大小上限由部署配置决定。

### 2.5 公开浏览与下载

- Caddy 直接提供公开根目录的文件列表和文件下载。
- 访客可以看到文件名、大小和修改时间，并点击文件名下载或打开文件。
- 文件不存在时返回未找到。
- 管理应用停止时，已存在文件仍可由 Caddy 提供。
- 管理端不提供复制链接、生成分享链接或管理链接的功能。

### 2.6 页面需求

| 页面 | 内容与操作 | 状态 |
| --- | --- | --- |
| 文件管理页 | 单层文件列表、文件选择框、上传按钮、删除按钮 | 加载中、空列表、提交中、成功、失败 |
| 公开文件页 | Caddy 文件列表和文件入口 | 正常列表、空列表、未找到 |

管理页面只需桌面端基础布局，不要求自定义公开页面样式。

### 2.7 运行约束

- 管理端和公开端均使用 HTTPS，并使用不同域名。
- 管理应用只能操作配置的公开根目录，不能访问服务器其他路径。
- 不允许上传或处理目录、符号链接及其他特殊文件。
- Caddy 只能读取公开目录，不能写入文件。
- 上传内容不能一次性完整载入应用内存。
- 配置、密码哈希、日志和上传临时文件不能放在公开目录中。

### 2.8 验收标准

1. 未提供或提供错误凭据访问管理端时，Caddy 返回 401；管理应用不能从公网绕过 Caddy 直接访问。
2. 管理页只显示公开根目录中的普通文件，不显示目录、符号链接或其他特殊文件。
3. 管理员选择一个文件并提交后，上传成功，列表中出现该文件，公开端可以获取完整内容。
4. 上传中断、超出限制或写入失败时，公开端看不到残缺文件。
5. 上传同名文件时操作失败，原文件保持不变。
6. 管理员确认删除后，文件从管理列表和公开端消失；取消确认时文件不变。
7. 访客无需认证即可浏览和下载公开文件。
8. 管理应用停止后，Caddy 仍能提供已有文件。

## 3. 后续可能扩展

以下功能不属于当前版本，需要出现实际需求后再设计和实现：

- 多文件上传、拖放上传、上传进度、分块上传和断点续传。
- 目录与多层浏览、新建目录、移动和目录删除。
- 文件重命名、同名覆盖策略、批量操作和回收站。
- 复制公开地址、分享 Token、密码、有效期、下载次数限制和私有文件。
- 文件描述、标签、搜索、排序、预览和下载统计。
- 应用内登录、退出、多管理员、角色和权限管理。
- 远程 URL 下载、BT/Magnet、WebDAV 和同步客户端。
- S3 等对象存储、多服务器、独立 API、CLI 和移动客户端。
